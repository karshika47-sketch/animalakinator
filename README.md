#  Animal Akinator

Animal Akinator is a fun interactive guessing game built using **HTML, CSS, and JavaScript**. The game asks up to **20 Yes/No questions** and uses the answers to guess the animal the player is thinking of.

##  Features

*  50+ different animals
*  Maximum 20 questions
*  Animal elimination logic
*  Question progress tracking
*  Interactive Yes/No buttons
*  Play Again option
*  Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

##  How to Play

1. Think of an animal.
2. Answer the questions with **Yes** or **No**.
3. The game analyzes your answers.
4. After a maximum of 20 questions, it guesses your animal.
5. Click **Play Again** to start a new game.
## How to Run
Download or clone this repository and open **`index.html`** in any web browser.
##  Purpose
This project was created to practice **JavaScript logic, conditional statements, data handling, and interactive web development** while building a fun game.
